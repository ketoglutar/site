# MATVIX portfolio

Иммерсивное двуязычное портфолио motion-дизайнера и видеомонтажёра.

## Запуск

```powershell
npm install
npm run dev
```

Production-сборка:

```powershell
npm run build
npm run preview
```

## Публикация на GitHub Pages

Проект уже подготовлен для репозитория `ketoglutar/site`. При сборке в GitHub
Actions Vite автоматически использует базовый путь `/site/`, поэтому видео,
постеры, портрет и JS/CSS корректно открываются по адресу:

`https://ketoglutar.github.io/site/`

Первичная публикация:

1. В GitHub откройте `Settings → Pages`.
2. В разделе `Build and deployment` выберите `Source: GitHub Actions`.
3. Отправьте файлы в ветку `main`:

```powershell
git add .
git commit -m "Prepare MATVIX portfolio for GitHub Pages"
git push -u origin main
```

Workflow `.github/workflows/deploy-pages.yml` автоматически выполнит
`npm ci`, проверку TypeScript, production-сборку и публикацию папки `dist`.
Последующие push в `main` также будут обновлять сайт автоматически. Ручной
запуск доступен во вкладке `Actions` через `Run workflow`.

Локальная проверка обычной сборки:

```powershell
npm run build
npm run preview
```

Проверка сборки с тем же базовым путём, что и на GitHub Pages:

```powershell
$env:VITE_BASE_PATH = "/site/"
npm run build
Remove-Item Env:VITE_BASE_PATH
```

## Локальная админка

Панель скрыта из публичной навигации. Для входа владелец открывает сайт с
параметром `?admin=1`, например `https://matvix.art/?admin=1`. Панель позволяет
добавлять и удалять ролики без изменения кода. Файлы сохраняются в IndexedDB
текущего браузера и сразу появляются в галереях. Это локальная библиотека:
загрузка на одном устройстве не изменяет сайт у других посетителей.

Поддерживаются MP4, WebM и MOV: до 250 МБ на файл, до 50 роликов и до 1 ГБ
суммарно. Пакетная загрузка выполняется одной транзакцией — при ошибке не
сохраняется ни один файл из выбранной группы.

### Как передать админку другому человеку

1. Откройте сайт с параметром `?admin=1` в браузере, где уже добавлены ролики.
2. В блоке «Передача панели» нажмите «Скачать копию».
3. Передайте полученный файл `*.matvix-backup` другому человеку.
4. На другом устройстве откройте этот же адрес с `?admin=1` и нажмите
   «Импортировать».
5. Подтвердите замену локальной видеотеки.

Файл резервной копии бинарный: видео не кодируются в base64. Перед записью
проверяются версия manifest, размеры, MIME-типы, смещения и SHA-256 каждого
ролика. Импорт либо заменяет всю локальную видеотеку одной транзакцией, либо не
меняет её вовсе.

Важно: файл передаёт содержимое локальной панели, но не создаёт общий аккаунт и
не публикует изменения для всех посетителей. Для совместной онлайн-админки
потребуются серверное хранилище и авторизация.

Контакты и все тексты RU/EN находятся в `src/lib/copy.ts`, основные страницы —
в `src/App.tsx`, визуальная система — в `src/styles.css`.
