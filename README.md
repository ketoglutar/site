# MATVIX portfolio

Иммерсивное двуязычное портфолио motion-дизайнера и видеомонтажёра.

## Запуск

```powershell
npm install
npm run dev
```

Production-сборка:

```powershell
npm run build
npm run preview
```

## Локальная админка

Кнопка «Админка» позволяет добавлять и удалять ролики без изменения кода. Файлы
сохраняются в IndexedDB текущего браузера и сразу появляются в галереях. Это
локальная библиотека: загрузка на одном устройстве не изменяет сайт у других
посетителей.

Поддерживаются MP4, WebM и MOV: до 250 МБ на файл, до 50 роликов и до 1 ГБ
суммарно. Пакетная загрузка выполняется одной транзакцией — при ошибке не
сохраняется ни один файл из выбранной группы.

### Как передать админку другому человеку

1. Откройте «Админку» в браузере, где уже добавлены ролики.
2. В блоке «Передача панели» нажмите «Скачать копию».
3. Передайте полученный файл `*.matvix-backup` другому человеку.
4. На другом устройстве откройте этот же сайт и выберите «Админка» →
   «Импортировать».
5. Подтвердите замену локальной видеотеки.

Файл резервной копии бинарный: видео не кодируются в base64. Перед записью
проверяются версия manifest, размеры, MIME-типы, смещения и SHA-256 каждого
ролика. Импорт либо заменяет всю локальную видеотеку одной транзакцией, либо не
меняет её вовсе.

Важно: файл передаёт содержимое локальной панели, но не создаёт общий аккаунт и
не публикует изменения для всех посетителей. Для совместной онлайн-админки
потребуются серверное хранилище и авторизация.

Контакты и все тексты RU/EN находятся в `src/lib/copy.ts`, основные страницы —
в `src/App.tsx`, визуальная система — в `src/styles.css`.
